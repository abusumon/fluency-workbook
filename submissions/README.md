# Submissions

Solutions to Fluency Workbook exercises, one file per exercise, grouped by chapter.

## How to add one

1. In the workbook, open the exercise and choose **Submit code**.
2. Paste your working code, pick the language, and choose **Commit to GitHub**.
3. GitHub opens with the file name and code filled in. Press **Commit changes**.

The public workbook at <https://abusumon.github.io/fluency-workbook/> reads this folder directly, so the solution appears under its exercise straight away (GitHub Pages may take a minute to refresh).

## File names

`submissions/<chapter>-<chapter-title>/<exercise label>-<exercise-title>.<py|cpp|txt>`, for example
`submissions/12-graphs-bfs-dfs-union-find/12.A2-find-a-safe-cell-before-the-blast.py`. Files with other names are kept but not linked to an exercise.
